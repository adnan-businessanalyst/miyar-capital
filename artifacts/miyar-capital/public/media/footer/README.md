# Footer background assets

Hardcoded footer chrome for the site. Content and colours live in
`src/site/footer.ts` — not Site Manager.

## Upload

Put the background image here:

| File | Notes |
|------|--------|
| `footer-bg.jpg` | Recommended. Also accepts `.png` / `.webp` with the same basename. |

Suggested size: about **1920 × 600–900**, JPG ~200–500 KB, soft enough to sit under the navy overlay.
