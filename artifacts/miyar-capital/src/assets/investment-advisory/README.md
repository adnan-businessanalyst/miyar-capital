# Investment Advisory / arrangement media

Place files here, then copy into `public/media/investment-advisory/` and run:

```bash
node ./scripts/generate-media-manifest.mjs
```

## Section background — `ia-bg`

Inside the rounded Investment Advisory card (Priority / Trust / Partnership).

| File | Use |
|------|-----|
| `ia-bg.mp4` | Looping video background (preferred when present) |
| `ia-bg.avif` / `.webp` / `.jpg` / `.png` | Still background (also used as video poster) |

## Arrangement intro image — `ia-intro`

Right-side image on Arrangement Management intro.

| File | Use |
|------|-----|
| `ia-intro.avif` (or `.webp` / `.jpg` / `.png`) | Intro split media |

## Arrangement detail section — `details-pg`

Background for Arrangement Management → “More Detailed Information”.

| File | Use |
|------|-----|
| `details-pg.png` (or `.avif` / `.webp` / `.jpg`) | Full-bleed section background |

## Process timeline — `ia-process-1` … `ia-process-5`

| File | Step |
|------|------|
| `ia-process-1.*` | 01 — Client meeting / objectives |
| `ia-process-2.*` | 02 — Asset / liability analysis |
| `ia-process-3.*` | 03 — Strategic asset allocation |
| `ia-process-4.*` | 04 — Implementation |
| `ia-process-5.*` | 05 — Monitoring & evaluation |

Accepted still extensions (preferred order): `.svg` · `.avif` · `.webp` · `.jpg` · `.jpeg` · `.png`
